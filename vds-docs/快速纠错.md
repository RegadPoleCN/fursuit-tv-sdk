# 快速纠错

## 令牌定义

旧版 VDS 开发者平台中存在3种令牌：`accessToken`、`apiKey`、`OAuth_token`

也存在3种请求头：`Authorization`、`X-Api-Key`、`X-OAuth-Access-Token`

- `Authorization: Bearer <accessToken>`：开放平台签名，用于验证请求的来源。
- `X-Api-Key: <apiKey>`：开放平台签名，用于验证请求的来源。
- `X-OAuth-Access-Token: <OAuth_token>`：用户访问令牌，用于调用 VDS 账户系统的 API。

**由于 `accessToken` 和 `apiKey` 完全相同，本文档默认推荐使用`X-Api-Key: <apiKey>`作为请求头**

***`X-OAuth-Access-Token: <OAuth_token>`作为历史遗留已进入deprecated状态，不推荐使用。***

---

**新版开发者平台推荐如下令牌：**

- `X-Api-Key: <apiKey>`：开放平台签名，用于验证请求的来源。
- `Authorization: Bearer <OAuth_token>`：用户访问令牌，仅用于调用 VDS 账户系统的 API。

**其中`Authorization: Bearer <OAuth_token>`为 VDS 账户系统独享。仅可作为OAuth中调用`用户信息端点`的令牌，获取需调用`签名交换端点`。**

## API地址

默认节点：`https://open-global.vdsentnet.com`

***由于各种原因，只推荐使用默认节点。***
