
# 热门推荐

按热度返回热门档案。

权限节点：`furtv.discovery.popular`

## 请求头

- `X-Api-Key: <apiKey>`

## 请求地址

- `GET /api/proxy/furtv/popular`

## 查询参数

- `limit`：可选，默认 `10`，范围 `1-25`
