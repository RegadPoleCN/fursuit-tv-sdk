
# 物种列表

获取公开档案中的物种统计。

权限节点：`furtv.discovery.species`

## 请求头

- `X-Api-Key: <apiKey>`

## 请求地址

- `GET /api/proxy/furtv/species`

## 成功响应示例

```json
{
  "success": true,
  "species": [
    {
      "species": "狐",
      "count": 128
    },
    {
      "species": "狼",
      "count": 91
    }
  ],
  "total": 324,
  "requestId": "e9c5e5f0-cbf2-4618-977a-5e663c76737a"
}
```
