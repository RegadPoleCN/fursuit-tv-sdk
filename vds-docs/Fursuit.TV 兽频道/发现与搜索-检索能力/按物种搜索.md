
# 按物种搜索

按指定物种查询公开档案。

权限节点：`furtv.discovery.species.search`

## 请求头

- `X-Api-Key: <apiKey>`

## 请求地址

- `GET /api/proxy/furtv/search/species/:species`

## 路径参数

- `species`：物种名称（如 `狐`）

## 查询参数

- `page`：可选，默认 `1`
- `limit`：可选，默认 `20`，最大 `20`
- `cursor`：可选，游标分页

## 请求示例

```bash
curl -X GET https://open-global.vdsentnet.com/api/proxy/furtv/search/species/猫?limit=50 \
     -H "X-Api-Key: eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJzdWIiOiJ2..."
```
