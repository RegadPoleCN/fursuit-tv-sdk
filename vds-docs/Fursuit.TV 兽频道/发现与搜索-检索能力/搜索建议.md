
# 搜索建议

获取自动补全建议。

权限节点：`furtv.discovery.search.suggestions`

## 请求头

- `X-Api-Key: <apiKey>`

## 请求地址

- `GET /api/proxy/furtv/search/suggestions`

## 查询参数

- `q`：必填，至少 2 个字符，使用`URL Encoding`编码

## 成功响应示例

```json
{
  "success": true,
  "suggestions": ["fox_demo", "狐狐", "foxmaker"],
  "requestId": "011f90f4-95a4-44c5-9bb5-5f9fd7e492be"
}
```
