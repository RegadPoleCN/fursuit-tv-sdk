
# 搜索

按关键词搜索公开档案。

权限节点：`furtv.discovery.search`

## 请求头

- `X-Api-Key: <apiKey>`

## 请求地址

- `GET /api/proxy/furtv/search`

## 查询参数

- `q`：必填，搜索关键词，使用`URL Encoding`编码
- `type`：可选，默认 `all`，支持 `all` / `interest` / `destination` / `location`
- `page`：可选，默认 `1`
- `limit`：可选，默认 `20`
- `cursor`：可选，游标分页
