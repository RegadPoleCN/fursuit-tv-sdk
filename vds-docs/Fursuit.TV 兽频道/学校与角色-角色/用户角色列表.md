
# 用户角色列表

获取指定用户的角色（崽崽）列表。

权限节点：`furtv.characters.user`

## 请求头

- `X-Api-Key: <apiKey>`

## 请求地址

- `GET /api/proxy/furtv/characters/user/:username`

## 路径参数

- `username`：用户名
