
# 主题包清单

获取主题包 manifest 清单。

权限节点：`furtv.themepacks.manifest`

## 请求头

- `X-Api-Key: <apiKey>`

## 请求地址

- `GET /api/proxy/furtv/theme-packs/manifest`
