
# 用户访客记录

获取指定用户的访客记录。

权限节点：`furtv.users.visitors`

## 请求头

- `X-Api-Key: <apiKey>`

## 请求地址

- `GET /api/proxy/furtv/users/:username/visitors`

## 路径参数

- `username`：用户名

## 成功响应示例（开启访客详情）

```json
{
  "success": true,
  "visitors": [
    {
      "visit_id": 123456,
      "visitor_id": 66,
      "visitor_username": "wolf_demo",
      "visitor_nickname": "狼狼",
      "visitor_avatar": "https://example.com/avatar-66.jpg",
      "created_at": "2026-03-21T09:20:12.000Z"
    }
  ],
  "total_views": 1,
  "total_login_visits": 1,
  "total_login_visitors": 1,
  "has_more": true,
  "isOwner": false,
  "requestId": "d1aaac11-2b06-4f66-a31d-fad9c0f15670"
}
```

## 成功响应示例（未开启访客详情）

```json
{
  "success": true,
  "visitors": [],
  "message": "访客详情未开启",
  "isOwner": false,
  "requestId": "7fc214f6-d0e0-4ae9-aaf3-0f421775d88a"
}
```
