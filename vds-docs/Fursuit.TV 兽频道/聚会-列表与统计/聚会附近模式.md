
# 聚会附近模式

***participants为预留字段，现阶段不处理***

返回附近聚会，并附带当前用户“想去/去向”聚会 ID 列表。

权限节点：`furtv.gatherings.nearbymode`

## 请求头

- `X-Api-Key: <apiKey>`

## 请求地址

- `GET /api/proxy/furtv/gatherings/nearby-mode`
