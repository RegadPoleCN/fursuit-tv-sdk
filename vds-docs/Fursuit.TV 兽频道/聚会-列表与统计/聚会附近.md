
# 聚会附近

返回时间窗口内可展示定位的聚会坐标。

权限节点：`furtv.gatherings.nearby`

## 请求头

- `X-Api-Key: <apiKey>`

## 请求地址

- `GET /api/proxy/furtv/gatherings/nearby`
