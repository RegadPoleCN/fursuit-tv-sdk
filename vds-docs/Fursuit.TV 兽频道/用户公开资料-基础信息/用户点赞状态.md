
# 用户点赞状态

查询当前账号对目标用户的点赞状态与可点赞信息。

权限节点：`furtv.fursuit.likestatus`

## 请求头

- `X-Api-Key: <apiKey>`

## 请求地址

- `GET /api/proxy/furtv/fursuit/like-status/:username`

## 路径参数

- `username`：目标用户名

## 成功响应示例

```json
{
  "success": true,
  "like_count": 233,
  "is_liked": false,
  "days_until_can_like": 0,
  "requestId": "27643bc0-5001-4f5a-ab05-8ef4f752fd35"
}
```
