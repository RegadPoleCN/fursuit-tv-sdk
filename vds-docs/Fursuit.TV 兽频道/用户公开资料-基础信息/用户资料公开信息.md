
# 用户资料公开信息

按用户名获取公开资料页面数据。

权限节点：`furtv.users.profile`

## 请求头

- `X-Api-Key: <apiKey>`

## 请求地址

- `GET /api/proxy/furtv/users/:username`

## 路径参数

- `username`：用户名
