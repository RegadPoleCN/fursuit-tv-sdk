# Today 接入与截图保护

VDP 开放的是兽频道 Today 的公开只读能力，不开放发布、编辑、删除、举报、浏览计数或 paw 这类会改变业务状态的接口。

## 内容保护

VDP 会过滤作者设置为不允许截图的 Today 内容。第三方应用无法通过 VDP 获取这些 Today 的正文、图片、作者卡片或详情页面数据。

列表类接口会直接跳过受保护内容。详情类接口如果命中受保护内容，会返回空内容结果`null`。

## 图片返回

Today 属于兽频道内容接口，仍遵循兽频道图片返回规则：默认不返回原始图片直链。应用需要通过`兽频道图片返回`能力审核后，才会拿到 VDP 可信代理后的水印图。
