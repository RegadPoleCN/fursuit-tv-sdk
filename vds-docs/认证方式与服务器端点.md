
# 认证方式与服务器端点

本页用于说明拿到签名后，业务端点如何携带令牌发起请求。  
接口文档未单独说明时，默认按本页认证方式执行。

## 1. 服务器端点

默认节点：`https://open-global.vdsentnet.com`

## 2. 默认认证方式（拿到签名后）

业务端点请求可使用以下任一方式：

**由于 `accessToken` 和 `apiKey` 完全相同，本文档默认推荐使用方式一**

1. `X-Api-Key: <apiKey>`
2. `Authorization: Bearer <accessToken>`

说明：

- 两者二选一。
- 同时传入时，服务端优先使用 `X-Api-Key`。

## 3. 签名获取与换新

签名获取与换新流程请参考：

- `基础接口/签名交换`
- `基础接口/签名换新`

## 4. RequestID 返回规则

平台所有请求都会返回 `requestId`：

- Response Header：`x-request-id`
- JSON Body 字段：`requestId`
